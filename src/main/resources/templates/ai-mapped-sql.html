Select AI SQL 메모리

로그인 계정의 DB 권한으로 조회 가능한 메모리 SQL 매핑입니다. SELECT AI로 시작하는 원문만 표시하며, conversation 설정과 무관합니다. 캐시에서 제거되면 사라집니다. 스키마별 이력이나 실행 성공·결과 행을 의미하지 않습니다. 변환 시각은 DB 기준이며 조회 중 목록이 달라질 수 있습니다.
조회 권한

실제 목록 조회 결과로 판단합니다. 조회 가능은 접근 권한을 확인했다는 뜻이며, 검색 결과는 0건일 수 있습니다.

권한이 없으면 ADMIN으로 접속해 조회할 계정에 아래 읽기 권한을 부여하세요. 이미 조회 가능이면 추가 부여는 필요 없습니다.

DB_USER를 실제 조회할 로그인 계정명으로 바꾸세요.

권한 부여 후 이 화면의 새로고침을 누르세요. 선택 스키마가 아닌 로그인 계정 기준이며, 본인 스키마의 기록만 보도록 제한하는 권한은 아닙니다.

ORA-00942는 권한 부족 또는 뷰 미지원일 수 있습니다. ADMIN에서도 접근할 수 없다면 DB 지원 여부와 권한을 확인하세요.
