Agent Memory

저장된 기억을 조회하고 검색합니다. 조회는 메모리 추출이나 모델 호출을 수행하지 않습니다.

저장된 메모리 조회

Select AI 대화는 현재 이 저장소에 연결된 프로필의 원본 질문·응답입니다. 저장소에 추출된 장기 기억과 다르며, 연결 변경 이전의 사용 관계를 증명하지는 않습니다.

메모리 형태란? · ?

장기 기억은 대화에서 추출한 사실·선호 등 재사용할 정보입니다. 메시지는 대화의 개별 발화이며 단기 문맥의 원본입니다. 요약은 대화 내용을 압축한 기록, 사용자·에이전트 정보는 참여자의 설명입니다. 단기·장기는 역할 구분이며 실제 보관 기간을 보장하지 않습니다. Select AI 원본 대화는 별도 대화 저장소에서 관리되어 메시지 목록이 비어 있을 수 있습니다.

ID의 의미 · ?
Store ID
여러 대화의 기억을 담는 저장소 식별자입니다.
Record ID
메시지·기억·요약 한 건의 식별자입니다. 참여자 정보는 Actor ID를 표시합니다.
Thread ID
기록이 속한 대화 묶음입니다. Select AI에서 추출한 기억은 원본 Conversation ID와 연결됩니다.
User / Agent ID
기억이 연결된 사용자와 에이전트 식별자입니다. 앱 로그인 이름과 같다고 가정하지 않습니다.
Space ID
기억의 공간·범위를 구분하는 식별자입니다. 없는 값은 미지정으로 표시합니다.
