DBC_AI_QUERY

호출 DB 사용자의 권한·프로필·용어사전·온톨로지를 사용합니다. MCP 연결 계정과 최종 사용자는 같지 않을 수 있습니다. 사용자별 접근 제어는 VPD·DDS 등 DB 설정이 필요합니다.

앱 밖에서 호출
Database Tools MCP의 매개변수형 SQL 도구에서 아래 호출을 등록합니다. 호출 옵션은 도구 설정에 고정하고 질문만 바인드하는 구성을 권장합니다. Agent도 같은 패키지를 사용자 정의 도구로 호출할 수 있습니다. 여기서는 외부 도구·권한을 자동 등록하지 않습니다.

    
-- First verify evidence without an AI request.
SELECT DBC_AI_QUERY.ASK(
  p_question => :question, p_profile => :profile,
  p_use_glossary => 1, p_use_ontology => 0,
  p_mode => 'CONTEXT') AS RESPONSE FROM DUAL;

-- With ontology: JSON array of approved table/view names.
-- Set p_mode to SQL or QUERY only when AI invocation is intended.
SELECT DBC_AI_QUERY.ASK(
  p_question => :question, p_profile => :profile,
  p_use_glossary => 1, p_use_ontology => 1,
  p_tables => :table_names_json, p_mode => 'CONTEXT') AS RESPONSE FROM DUAL;
