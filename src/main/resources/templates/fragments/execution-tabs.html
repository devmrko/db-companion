저장된 대화 Agent 실행 Select AI SQL / GENERATE 구분 기준

저장된 대화 — 보관된 질문·응답 한 건 기준입니다. Agent가 남긴 대화도 포함될 수 있습니다.

Agent 실행 — Team 실행 ID(TEAM_EXEC_ID) 기준입니다. 실행 안의 Task를 TASK_ORDER 순으로 구분하며, 같은 Task가 반복돼도 합치지 않습니다.

Select AI SQL — SQL 매핑·공유 SQL·AWR·감사 로그를 구분해 조회합니다. 원천별 수집 범위와 보존 기간이 다릅니다.

같은 요청이 여러 탭에 나타날 수 있습니다. 대화 ID만으로 하나의 Team 실행이라고 판단하지 않습니다.
