    대화에서 새 메모리 추출 · 별도 작업

    대화 ID는 원본 대화를 식별합니다. Memory Store ID는 여러 대화에서 재사용할 저장소를 식별하며, 두 ID는 다릅니다.

    최근 50개 대화입니다. 추출은 저장 내용을 읽는 작업이 아니라 LLM으로 기억을 만드는 작업이며 비용이 발생할 수 있습니다.

    현재 프로필에 연결된 저장소로 추출합니다. 다른 프로필이 섞인 대화는 추출하지 않습니다.

    Memory Store 생성

    영문자로 시작하는 125자 이내 이름입니다. 영문·숫자·_·$·#을 사용할 수 있으며, 소문자는 대문자로 저장됩니다. 예: agentmemory → AGENTMEMORY

    선택한 프로필의 LLM과 embedding_model을 사용합니다. 다른 프로필의 설정을 복사하지 않습니다.

    프로필의 필수 설정을 확인 중입니다.
