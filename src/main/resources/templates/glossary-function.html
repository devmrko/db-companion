용어사전 검색 함수 만들기

자연어 질문 → 용어·별칭 검색 → 업무 정의·SQL 기준 JSON. AI 호출이나 SQL 실행은 하지 않습니다.

1. 생성 조건 확인

로그인 소유 스키마에만 생성합니다. 기존 객체를 교체하거나 권한을 부여하지 않습니다.

    2. 함수 코드 확인

    입력: 질문 CLOB(최대 8,000자). 출력: 질문·토큰·일치 용어·정의·SQL 기준을 담은 JSON CLOB. 활성 용어만 검색하며 30개 초과·근거 크기 초과는 오류로 알립니다.

    처리 순서 · 패키지 SEARCH
    
    
    
    
    생성은 DDL이며 암시적 COMMIT이 발생합니다. 실패해도 객체가 남을 수 있습니다. 자동 삭제·교체·재시도하지 않습니다.
