# 온톨로지 관계도 개선

테이블의 관계를 읽고 검토하는 사용자가 연결 구조와 업무명을 쉽게 파악하도록,
관계도 탭을 React Flow와 ELK로 구성한다. 기존 목록·검토·승인 API와 버전 검사는 유지한다.

## 동작

- 기본 화면은 FK·승인 관계를 표시하며 후보·재검토 관계는 토글로 추가한다.
- 업무명, 테이블명, 관계에 사용된 주요 컬럼을 카드에 표시한다.
- ELK 계층 배치로 왼쪽에서 오른쪽으로 정렬한다. 화면 이동·확대·노드 이동은 DB에 저장하지 않는다.
- 선택한 노드 주변을 강조한다. 목록에서 숨겨진 후보를 선택하면 해당 관계를 드러낸다.
- 상세 패널은 접을 수 있고 미저장 입력 보호는 기존 검토 흐름을 따른다.
- 키보드 사용자는 기존 검색·관계 목록으로도 같은 검토 기능에 접근한다.

## 구현 경계

React는 그래프 영역에만 마운트한다. 번들은 로컬 정적 자원으로 제공하고 외부 CDN을 호출하지 않는다.
의존성은 잠금 파일로 고정한다. npm 빌드로 번들과 제삼자 라이선스 고지를 생성한다.
ELK는 브라우저에서 계산하며 저장 API를 호출하지 않는다. 비동기 배치가 완료되기 전에
새 데이터가 오거나 화면이 폐기되면 이전 결과를 적용하지 않는다.
ERD 및 다른 그래프 화면은 기존 구현을 유지한다. 이번 범위는 온톨로지 관계도 탭이다.

## 검증

후보 필터, 교차 스키마, 복수 연결, 빈 그래프, 겹침 없는 배치, 선택 및 위치 유지,
미저장 입력 보호를 검사한다. Java·JavaScript·PMD·publication 검사와 별도 localhost
화면 검증을 수행한다. 실제 DB 쓰기 및 배포는 이 설계서가 승인하지 않는다.
