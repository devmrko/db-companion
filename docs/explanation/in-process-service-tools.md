# 기존 서비스를 사용하는 설정 도우미

대상: 자연어 요청으로 프로필과 기존 업무 지식 연결을 확인·수정하려는 사용자. 기존 Java 서비스를 Spring AI의 인프로세스 ToolCallback으로 등록해 같은 앱 안에서 호출한다. LLM 호출은 기존 ADB 인터페이스를 사용한다. 별도 MCP 서버·외부 모델 공급자·새 설정 저장소는 추가하지 않는다.

## 구현 계약

- 공통 계약에 서비스 역할·사용 상황·입출력 Schema·예시·결과 화면 종류를 정의한다. AI 인스트럭션과 화면 안내가 같은 계약을 읽는다. 업무 절차는 서비스 ID를 참조한다.
- 최초 등록: 기존 설정 준비 조회, 이력 준비 조회, 프로필 옵션 조회, 사전 준비 조회, 시멘틱 소스 조회, 기존 소스 연결안 생성. 등록 이름과 실제 핸들러가 일치하지 않으면 시작 시 실패한다.
- 서버가 고정한 로그인 세션·소유자·대상 프로필·목적을 ToolContext로 전달한다. 모델은 소유자·프로필·승인·SQL·메서드명을 지정할 수 없다. 연결안 도구의 source 인자만 명세대로 받는다.
- 소스 연결안은 실제 활성 목록과 현재 연결을 조회해 기존 항목을 보존한다. 변경은 실행하지 않는다. 최종 제안이 해당 서버 측 계획과 일치할 때만 기존 변경 확인 화면으로 이어진다.
- 적용은 명시적 사용자 확인, 새 버전/선행 조건/소스 활성 상태 확인, 기존 ProfileEditService.save의 트랜잭션·이력·저장값 검증을 사용한다. 미리보기는 단일 사용/유효기간을 갖고 대상 변경·새 요청·실패 시 무효화한다.
- 도구별 1회, 여섯 도구와 최종 설명을 포함한 AI 최대7회. 별도 Tool 사용 동의를 받은 경우만 실행한다. 결과 크기 제한·엄격한 응답/인자 검사·자동 재시도 금지를 유지한다.
- JSON 객체·배열 결과 PRE는 공통 HTML 뷰의 항목/값·목록·중첩 펼침으로 표시한다. 원문 복사/다운로드를 보존하며 기존 PRE는 데이터 원본으로 유지한다. 데이터는 텍스트 노드로 표시한다. 250,000자·깊이32를 넘거나 JSON이 아닌 내용은 원문을 유지한다.
- JSON 입력은 기존 프로필의 타입별 편집기·소스 선택기 등을 유지한다. 이번 변경은 결과 표시 공통화이며, 임의 JSON을 수정하는 범용 폼 편집기를 추가하지 않는다. 저장·승인 API의 의미는 변경하지 않는다.

## 완료 기준

정형 모델 응답으로 실제 Spring ToolCallback→기존 서비스→실제 결과 전달을 검증한다. 소스 연결은 기존 연결 보존·비활성/미등록 소스 거절·누락/추가 인자·잘못된 타입·신원 변경·버전 변경·토큰 재사용·미동의·쓰기 후 불명확 결과를 검사한다. JSON은 HTML 삽입 방지, 큰 정수/중복 키의 원문 보존, 동적 갱신·숨김·비 JSON 복원, 모바일 배치·창 내부 스크롤을 확인한다.

새 사전·콜백·Source 생성, 계정/권한 변경, OCI/APEX 전체 자동 구성은 이번 등록 범위에 포함하지 않는다. 실제 모델/DB 시험과 가짜 응답 시험을 구분해 보고한다. 사용자 8080 앱 반영과 소스 공개도 검증 완료 후 기존 승인 범위에서 별도로 기록한다.
